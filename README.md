# work-items

A markdown work-item tracker in git. It covers the loop design, backlog, refine, implement, merge and sync, one command per verb, plus an orchestrate pipeline and agents.

## Install
`claude plugin marketplace add piwi91/work-items`, then `claude plugin install work-items@work-items`, then `/work-items:init` or `/work-items:upgrade`. Then `/work-items:auto` runs the loop unattended; `/work-items:inbox` shows what needs you.
