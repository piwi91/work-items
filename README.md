# work-items

A markdown work-item tracker in git. It covers the loop design, backlog, refine, implement, merge and sync, plus an orchestrate pipeline and agents.

## Install
`claude plugin marketplace add <path-or-git-url>`, then `claude plugin install work-items@work-items`, then `/work-items:wi init` or `/work-items:wi upgrade`.
